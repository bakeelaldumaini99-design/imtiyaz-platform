# منصة الإمتياز في الرياضيات

**تحت إشراف الأستاذ شاجع الدميني — من الفهم إلى التفوق**

منصة تعليمية إلكترونية تفاعلية لطلاب الصف الثالث الثانوي (القسم العلمي) في اليمن، بتصميم فاخر (كحلي × ذهبي) ودعم كامل للعربية RTL.

## المميزات

- تسجيل دخول بحساب **جوجل** (ضع `Google Client ID` في `src/config.ts` لتفعيله فعليًا)
- الوحدات السبع الكاملة للمنهج اليمني مع الدروس والمحاضرات
- **نظام مراقبة المستوى**: نقاط تفوق، ألقاب مستويات، مخطط شريطي وخريطة إتقان رادارية
- **مشغل فيديو آمن** بعلامة مائية متحركة باسم الطالب، واختيار الجودة والسرعة
- باقات اشتراك (أسبوعية / شهرية / فصلية / سنوية)
- **الدفع اليدوي عبر الكريمي** مع رفع الإيصال ومراجعة الإدارة
- لوحة إدارة: إحصائيات، قبول/رفض المدفوعات، مراقبة مستوى الطلاب، تصدير CSV
- تواصل مباشر مع المعلم عبر واتساب

## التشغيل

```bash
npm install
npm run dev
```

## البناء للنشر

```bash
npm run build
```

الإعدادات العامة (رقم الكريمي، الواتساب، بريد الإدارة، Google Client ID) في ملف `src/config.ts`.
